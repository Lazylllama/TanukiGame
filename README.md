# Tanuki Game (Name TBD)
You're a tanuki fighting for your life in dungeons to be able to pay back your debt following serious gambling problems. You have one chance to pay it back or it's over, turns out the last game he'll ever play is Tanuki Game.

> [!IMPORTANT]
> Running on Unity Editor v6000.5.9f1

> [!NOTE]
> This project is a work in progress, and is far from complete so keep that in mind!

# Download
You can download the game on the [Itch](https://lazylllama.itch.io/tanuki-game) page!

## Features
- Parrying (RMB)
  - Purple parry objects around the map
  - Enemy projectiles
- Dash (Shift)
- Melee attack (LMB)
- Camera system
  - Camera boundaries
  - Custom lookahead when falling down to see beneath you
- Self made main menu with options using Unity UI Documents
- RNG system for upgrade randomness
